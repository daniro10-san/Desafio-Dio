
# 🚀 O Caminho para um Profissional de Quality Assurance (QA)

## 📌 Sobre

Este repositório faz parte do desafio da DIO e tem como objetivo documentar os estudos iniciais na área de **Quality Assurance (QA)**, abordando conceitos fundamentais de qualidade, metodologias ágeis e controle de versão utilizando Git e GitHub.

---

## 🎯 Objetivo

Desenvolver uma base sólida para atuar como profissional de QA, compreendendo:

- Fundamentos de Qualidade de Software
- Metodologias Ágeis
- Controle de versão com Git
- Hospedagem de projetos no GitHub
- Boas práticas de documentação
- Fluxo de trabalho colaborativo
